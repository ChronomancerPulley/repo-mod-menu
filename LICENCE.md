## 🧩 About

**R.E.P.O. Companion** is a curated list of R.E.P.O. open-source tools:

- **Overlays** — on-screen helpers, layout notes, item tracker, minimap
- **Quality-of-Life Helpers** — inventory sorter, cosmetic loadout notes, overlay notes
- **Research Notes** — loot layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Item Tracker — highlight valuable loot through walls
- Minimap Overlay — see nearby rooms and extraction points
- Replay Notes — record and review runs
- Playback Speed — adjust movement speed for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Cosmetic Catalog — browse skins, colors, emotes
- Custom Loadout Notes — organize player cosmetics
- Outline Highlight — improved visibility for items and enemies

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-run
- Jump Buffer Notes — chain complex maneuvers in the editor
